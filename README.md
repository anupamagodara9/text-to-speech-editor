🗣️ Text To Speech Talker (Python)

A simple command-line Text-to-Speech (TTS) application built using the pyttsx3 Python library.
The program converts user-entered text into spoken audio using the system’s native speech engine.

✨ Features
- Converts text input into speech in real time
- Works offline (no internet required)
- Cross-platform support:
-   Windows → SAPI5
-   macOS → NSSpeechSynthesizer
-   Linux → eSpeak

- Interactive command-line interface
- Graceful exit using QUIT

🛠️ Technologies Used
- Python
- pyttsx3 (Text-to-Speech library)

🚀 Possible Enhancements
  Voice selection (male/female voices)
  Adjustable speech rate and volume
  Save speech output to audio files
  GUI interface using Tkinter or Streamlit
